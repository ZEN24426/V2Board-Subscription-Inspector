# V2Board Subscription Inspector

一个面向 **V2Board** 的轻量订阅地址查询与信息检查工具。

> 项目目前处于早期开发阶段，当前仅以 V2Board 为目标。功能、使用方式和兼容范围以实际发布版本为准。

## 项目简介

V2Board Subscription Inspector 用于查询和查看 V2Board 订阅地址相关信息，帮助用户更方便地了解自己的订阅数据。

- **当前目标：** V2Board
- **项目类型：** 订阅地址查询工具
- **许可证：** GNU General Public License v3.0（GPL-3.0）

## 使用与安全提醒

订阅地址通常包含访问凭据，任何获得该地址的人都可能使用它访问对应的订阅内容。请妥善保管你的订阅地址：

- 不要将真实订阅地址、Token 或其他凭据提交到 Git 仓库。
- 分享日志或截图前，请先移除其中的订阅链接及个人信息。
- 请仅查询你拥有或已获授权使用的订阅地址。

## 开发状态

项目正在持续开发中。详细功能、安装步骤和使用说明将在相关功能稳定后补充。
